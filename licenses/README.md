# licenses/

Carpeta reservada para los textos de licencia de terceros que deban
distribuirse junto con OSR Manager.

Estado actual: **vacía**. Ninguno de los componentes de terceros incluidos en
`css/` trae un fichero de licencia local en el proyecto (ver
`THIRD_PARTY_NOTICES.md` para el detalle de cada uno). Antes de una
distribución más amplia (o si se añade contenido de terceros con licencia
propia, p. ej. compendios OSE), copiar aquí el texto exacto de la licencia de
origen, por ejemplo:

```text
licenses/
├── TuiCss-LICENSE.txt
├── Perfect-DOS-VGA-437-LICENSE.txt
└── ...
```

No mezclar estos textos con el `LICENSE` (MIT) de la raíz, que cubre
únicamente el código original del proyecto.
