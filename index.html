Ayuda
Modos: cambia entre Mazmorra, Exterior y Combate con las pestañas del menú superior. Cada modo tiene sus propias fases y acciones en la barra de estado.
Grupo: añade personajes con el botón + del panel Grupo; haz clic en uno para ver o editar su ficha.
Mazmorra: registra sala/nivel, gestiona luz y efectos activos, tira dados de exploración con F5.
Exterior: viaja por la rejilla hexagonal (F3 o el botón Viajar), consulta terreno y genera encuentros.
Combate: inicia combate, tira iniciativa, usa N para pasar turno y aplica daño/curación/estados a cada combatiente.
Guardar: F2 guarda en el navegador; usa Archivo -> Exportar/Importar para mover la campaña entre dispositivos.
